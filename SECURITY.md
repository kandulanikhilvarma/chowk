# Security policy

## Report a problem

Do not open a public issue for a security problem. Send an email to **kandulanikhilvarma@gmail.com** with:

- What the problem is and what an attacker can do with it
- The steps to reproduce it
- The URL, route or database function that is affected

You get a reply within 3 days. When we confirm the problem, we fix it and tell you when the fix is live.

## Scope

In scope:

- The website at https://chowk-kandula.vercel.app
- The code in this repository, including the database migrations and row level security policies

Out of scope:

- Problems in Supabase, Vercel or Google themselves. Report those to the company.
- Denial of service, spam and social engineering of Chowk users

## Rules for testing

- Use your own accounts only. Do not read, change or delete data that belongs to other people.
- Stop and report as soon as you can see data that is not yours.
- Do not run automated scans that send large numbers of requests.
